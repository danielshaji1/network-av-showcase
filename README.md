# Daniel Shaji · Network & AV Fieldwork

A visual portfolio of network and audiovisual installation work, including projects in progress and completed installs.

## View the portfolio

The responsive gallery is built as a lightweight static site in [`index.html`](index.html). It features a selected project image, a field-photo gallery, and links to the original HEIC files.

To publish it with GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will provide the public site URL there.

## Add photos

1. Put the originals in `images/`.
2. Add a gallery card in `index.html` with a descriptive alt text, the correct image path, and a short caption.
3. Keep filenames stable and remove `.DS_Store` files before committing.

The gallery links each image to its original file. HEIC previews depend on browser support; the links remain available for viewing or download when a browser cannot preview the format.

Before publishing, check that photos do not reveal customer names, addresses, network diagrams, serial numbers, passwords, or other sensitive information, and get permission to publish customer-site photos.
